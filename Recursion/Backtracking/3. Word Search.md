# LeetCode 79 — Word Search

Problem link: [LeetCode 79 — Word Search](https://leetcode.com/problems/word-search/)

## 1. Problem Idea

This is a DFS + Backtracking problem.

The important recursion state is:

```text
(i, j, idx)
```

Meaning:

We are at board cell (i, j) and we are trying to match word[idx].

We start from every cell that matches the first character.

## 2. Pattern Recognition

From the current board cell, the next character can be in four directions:

```text
          up
           ↑
left  ← current → right
           ↓
         down
```

So the recursion is:

```text
current cell
    ↓
validate
    ↓
mark visited
    ↓
try 4 directions
    ↓
restore
    ↓
return result
```

This is the same core backtracking pattern:

CHOOSE → EXPLORE → UNDO

## 3. State

```text
backtrack(i, j, idx, board, n, m, word)
```

| Variable | Meaning |
| --- | --- |
| i | Current row |
| j | Current column |
| idx | Current character index in word |
| board | Grid |
| n | Number of rows |
| m | Number of columns |
| word | Target word |

The important state is:

```text
(i, j, idx)
```

i/j describe where we are and idx describes how much of the word we have matched.

## 4. Starting Point

We do not know which cell contains the first character.

Therefore:

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        if (board[i][j] == word.charAt(0)) {
            if (backtrack(i, j, 0, board, n, m, word)) {
                return true;
            }
        }
    }
}
return false;
```

Important: do not immediately do:

```java
return backtrack(...);
```

because the first matching starting cell may fail while another matching cell succeeds.

## 5. Base Case

```java
if (idx == word.length()) {
    return true;
}
```

Example:

word = "CAT"

C → idx 0
A → idx 1
T → idx 2

After successfully matching T, the next call has:

idx = 3

and:

3 == word.length()

means:

Every character has been matched.

Therefore the answer is true.

## 7. Four Directions

```java
int[][] directions = {
    {-1, 0}, // up
    {1, 0},  // down
    {0, 1},  // right
    {0, -1}  // left
};
```

Then:

```java
for (int[] dir : directions) {
    int new_i = i + dir[0];
    int new_j = j + dir[1];
}
```

## 8. Why idx + 1?

If the current cell matches:

word[idx]

then the next cell must match:

word[idx + 1]

Therefore:

```java
backtrack(new_i, new_j, idx + 1, ...);
```

## 9. Visited Cell

The same cell cannot be used twice in the same path.

Temporarily mark the current cell:

```java
char temp = board[i][j];
board[i][j] = '#';
```

Now another recursive call cannot use that cell because it no longer matches the required character.

This is equivalent to the ADD → RECURSE → REMOVE pattern from previous backtracking problems.

Here it becomes:

MARK → RECURSE → RESTORE

## 10. Parent Must Use the Recursive Result

Do not write:

```java
backtrack(...);
backtrack(...);
return true;
```

The parent needs to know whether any direction succeeded.

Conceptually:

direction 1 succeeds? → true
otherwise
direction 2 succeeds? → true
otherwise
direction 3 succeeds? → true
otherwise
direction 4 succeeds? → false

So:

```java
if (backtrack(...)) {
    ...
}
```

This is the same Boolean idea as:

take || skip

from subsequence-sum recursion, except here there can be up to four choices.

## 11. Important Review Note About the Current Code

Your latest code is very close, but there is still one backtracking issue.

You currently have:

```java

`board[i][j] = temp;`
```

If a path succeeds, the return true happens before restoring:

`board[i][j] = temp;`

So the board can remain modified.

The general rule is:

MARK
→ EXPLORE
→ RESTORE
→ RETURN

A safe structure is:

## 12. Current Code We Derived

```java
class Solution {
    int[][] directions = {
        {-1,0}, //up
        {1,0},  //down
        {0,1},  //right
        {0,-1}  //left
    };

    public boolean exist(char[][] board, String word) {
        int n = board.length;
        int m = board[0].length;
        int idx = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (board[i][j] == word.charAt(idx)) {
                    if (backtrack(i, j, idx, board, n, m, word)) {
                        return true;
                    }
                }
            }
        }
        return false;
    }

    private boolean backtrack(
            int i, int j, int idx,
            char[][] board, int n, int m,
            String wrd) {

        if (idx == wrd.length()) return true;

        if (i < 0 || i >= n ||
            j < 0 || j >= m ||
            board[i][j] != wrd.charAt(idx)) {
            return false;
        }

        char temp = board[i][j];
        board[i][j] = '#';

        for (int[] dir : directions) {
            int new_i = i + dir[0];
            int new_j = j + dir[1];

            if (backtrack(new_i, new_j, idx + 1,
                          board, n, m, wrd)) {
                return true;
            }
        }

        board[i][j] = temp;
        return false;
    }
}
```

## 13. Corrected Backtracking Core

To guarantee restoration even when a successful path is found:

```java
private boolean backtrack(
        int i, int j, int idx,
        char[][] board, int n, int m,
        String word) {

    if (idx == word.length()) {
        return true;
    }

    if (i < 0 || i >= n ||
        j < 0 || j >= m ||
        board[i][j] != word.charAt(idx)) {
        return false;
    }

    char temp = board[i][j];
    board[i][j] = '#';

    boolean found = false;

    for (int[] dir : directions) {
        int new_i = i + dir[0];
        int new_j = j + dir[1];

        if (backtrack(new_i, new_j, idx + 1,
                      board, n, m, word)) {
            found = true;
            break;
        }
    }

    board[i][j] = temp;
    return found;
}
```

## 14. Recursion Tree

For a successful path such as:

A → B → C → C → E → D

the recursion looks conceptually like:

```text
backtrack(A, idx=0)
├── invalid direction -> false
├── choose B, idx=1
│   ├── invalid direction -> false
│   └── choose C, idx=2
│       └── choose C, idx=3
│           └── choose E, idx=4
│               └── choose D, idx=5
│                   └── backtrack(next cell, idx=6)
│                       └── idx == word.length() -> SUCCESS
└── another direction -> false
```

At every node, the algorithm tries up to four neighboring cells. A neighbor
that is outside the board, already visited, or has the wrong character returns
`false` and its branch is abandoned.

A successful result propagates upward:

```text
idx = word.length()
        ↓
      true
        ↓
    parent true
        ↓
    parent true
        ↓
   starting cell true
```

## 15. Why This Is DFS + Backtracking

DFS

We go deeply into one possible path:

A
 ↓
B
 ↓
C
 ↓
...

Backtracking

When the path fails:

undo previous choice
try another direction

So:

DFS + state modification + undo

## 17. Key Mistakes Identified During Practice

Mistake 1 — Using board row as word index

Wrong idea:

word.charAt(i)

Correct:

word.charAt(idx)

because board coordinates and word progress are different dimensions.

Mistake 2 — Wrong boundary

Wrong:

i > n
j > m

Correct:

i >= n
j >= m

because the largest valid index is n - 1 / m - 1.

Mistake 3 — Only two directions

Word Search requires:

up
down
left
right

Mistake 4 — Ignoring recursive result

The result of each recursive choice must be used.

Mistake 5 — Returning from the first matching starting cell

A failed starting cell does not mean the whole board fails.

Mistake 6 — Returning success before restoring shared state

Whenever state is modified:

modify
→ explore
→ restore

## 18. Complexity

Let:

N = rows × columns
L = word length

We may start from every cell, and each step explores up to four directions. A common bound is:

O(N × 4 × 3^(L-1))

often simplified to:

O(N × 3^L)

The recursion depth is at most the word length:

O(L)

Because the board itself is modified in-place, no separate visited[][] matrix is necessary.

## 19. Interview Explanation

I try every cell as a possible starting point. For each matching cell, I run DFS with state (row, column, wordIndex). At each step I validate the current cell, temporarily mark it as visited, and explore the four adjacent directions for the next character. After exploring, I restore the original character so other paths are unaffected. If wordIndex reaches word.length(), the whole word has been matched.
