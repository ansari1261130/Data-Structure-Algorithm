# Recursion Revision Note — Reverse a Stack

Question: [Reverse a Stack](https://www.geeksforgeeks.org/problems/reverse-a-stack/1)

Pattern: Pop → Reverse Remaining → Insert at Bottom

## 1) Core idea

Given a stack, reverse it using recursion.

Example:

```text
Original stack: [1, 2, 3, 4]
TOP = 4
```

After reversing:

```text
[4, 3, 2, 1]
TOP = 1
```

Important requirement:

- use recursion
- do not use another stack

---

## 2) First observation

The key question is:

```text
What does reversing a stack actually mean?
```

Suppose:

```text
[1, 2, 3, 4]
      ↑
     TOP
```

If we pop:

```text
4
```

then the remaining stack becomes:

```text
[1, 2, 3]
```

If we recursively reverse that stack, we get:

```text
[3, 2, 1]
```

Now the removed value 4 must go to the bottom:

```text
[4, 3, 2, 1]
```

So the real operation is:

```text
Pop one element
→ reverse remaining stack
→ insert removed element at bottom
```

---

## 3) Important difference from sort stack

In Sort Stack, we insert the element at its correct sorted position.

Here, in Reverse Stack, we always insert at the bottom.

So:

- Sort Stack: value-based insertion
- Reverse Stack: bottom insertion

This is the main difference.

---

## 4) My initial thought

I initially thought:

```text
If I pop the element, then after recursion I can directly push it back.
```

But that is not enough.

Example:

```text
[1, 2, 3, 4]
```

Pop 4 → `[1, 2, 3]`

Reverse remaining → `[3, 2, 1]`

If we simply push 4 back, we get:

```text
[3, 2, 1, 4]
```

But the answer should be:

```text
[4, 3, 2, 1]
```

So direct push is wrong.

The removed element must go to the bottom, not the top.

---

## 5) The key question

How do we insert an element at the bottom of a stack using recursion?

Example:

```text
stack = [1, 2, 3]
element = 4
```

Wanted result:

```text
[4, 1, 2, 3]
```

Stack operations only provide:

```java
push()
pop()
peek()
```

There is no built-in `pushToBottom()`. So we must create it recursively.

---

## 6) insertElement() — insert at bottom

Function:

```java
insertElement(stack, element)
```

means:

```text
Insert the element at the bottom of the stack.
```

Base case:

```java
if (stack is empty) {
    push(element);
}
```

Example:

```text
[]
insert 4 -> [4]
```

---

## 7) If the stack is not empty

Suppose:

```text
stack = [1, 2, 3]
element = 4
```

We cannot just push 4 because that gives:

```text
[1, 2, 3, 4]
```

We want:

```text
[4, 1, 2, 3]
```

So we temporarily remove the top:

```text
pop 3 -> [1, 2]
```

Then recursively do:

```text
insertElement([1, 2], 4)
```

This continues until the stack becomes empty.

Then we push 4:

```text
[4]
```

Then restore 1, 2, 3:

```text
[4, 1, 2, 3]
```

---

## 8) The most important pattern

`insertElement()` follows:

```java
int remove = st.pop();
insertElement(st, element);
st.push(remove);
```

This is the same temporary-storage pattern as in Sort Stack.

But the purpose is different:

- Sort Stack: insert by sorted order
- Reverse Stack: insert at bottom regardless of value

---

## 9) Why do we have to pop everything?

Because the target element cannot reach the bottom while items still remain above it.

Example:

```text
stack = [1, 2, 3]
element = 4
```

We need:

```text
[4, 1, 2, 3]
```

So 4 must move below 1, 2, 3.

That means we must temporarily remove:

```text
3, 2, 1
```

until the stack is empty.

Only then can we push 4 at the bottom and restore the others.

---

## 10) Complete reverseStack() logic

```java
reverseStack(st)
```

means:

```text
if stack is empty:
    return

element = pop()
reverseStack(st)
insertElement(st, element)
```

This is:

```text
Remove one element
→ reverse remaining stack
→ insert removed element at bottom
```

## 11) Trace example

Original:

```text
[1, 2, 3, 4]
```

Call flow:

```text
reverseStack([1,2,3,4])
  -> pop 4
  -> reverseStack([1,2,3])
      -> pop 3
      -> reverseStack([1,2])
          -> pop 2
          -> reverseStack([1])
              -> pop 1
              -> reverseStack([])
              -> base case
```

Then recursion returns upward and inserts values at the bottom.

---

## 12) Recursion return flow

When the stack becomes empty, recursion starts returning upward.

```text
insert 1 at bottom -> [1]
insert 2 at bottom -> [2, 1]
insert 3 at bottom -> [3, 2, 1]
insert 4 at bottom -> [4, 3, 2, 1]
```

This is exactly the reverse.

---

Going down:

```text
[1,2,3,4]
  -> pop 4
[1,2,3]
  -> pop 3
[1,2]
  -> pop 2
[1]
  -> pop 1
[]
```

Base case reached.

Going up:

```text
insert 1 at bottom -> [1]
insert 2 at bottom -> [2,1]
insert 3 at bottom -> [3,2,1]
insert 4 at bottom -> [4,3,2,1]
```

## 14) Final Java code

```java
class Solution {

    public static void reverseStack(Stack<Integer> st) {

        if (st.isEmpty()) {
            return;
        }

        int element = st.pop();

        reverseStack(st);

        insertElement(st, element);
    }

    private static void insertElement(Stack<Integer> st, int element) {

        if (st.isEmpty()) {
            st.push(element);
            return;
        }

        int remove = st.pop();

        insertElement(st, element);

        st.push(remove);
    }
}
```

---

## 15) Code explanation — reverseStack()

```java
public static void reverseStack(Stack<Integer> st)
```

This function reverses the entire stack.

Base case:

```java
if (st.isEmpty()) return;
```

Then:

```java
int element = st.pop();
reverseStack(st);
insertElement(st, element);
```

Meaning:

```text
POP → REVERSE REMAINING → INSERT AT BOTTOM
```

---

## 16) Code explanation — insertElement()

This helper inserts the given element at the bottom.

If stack is empty:

```java
st.push(element);
return;
```

Otherwise:

```java
int remove = st.pop();
insertElement(st, element);
st.push(remove);
```

This reaches the bottom and restores the elements after insertion.

---

## 17) Why recursion inserts at the bottom

Example:

```text
stack = [1, 2, 3]
element = 4
```

The recursion removes:

```text
3, 2, 1
```

until the stack is empty.

Only then does it push 4:

```text
[4]
```

Then it restores:

```text
1, 2, 3
```

Final result:

```text
[4, 1, 2, 3]
```

This is how the recursion simulates bottom insertion without another stack.

---

## 18) Why we cannot just push the popped element

Direct push always puts the element on top.

Example:

```text
[1,2,3,4]
```

Pop 4 → `[1,2,3]`

Reverse remaining → `[3,2,1]`

Then direct push gives:

```text
[3,2,1,4]
```

But we need:

```text
[4,3,2,1]
```

Therefore, we need `insertElement` to place it at the bottom.

---

## 19) Key difference from Sort Stack

Sort Stack:

```text
pop element
→ sort remaining
→ insert at correct sorted position
```

Reverse Stack:

```text
pop element
→ reverse remaining
→ insert at bottom
```

Same structure, different insertion rule.

## 20) Same stack, no extra stack

We only use one stack:

```java
Stack<Integer> st;
```

No second stack is needed.

The recursion call stack acts as temporary storage while we remove items and restore them in order.

---

## 21) Important recursion pattern

This problem teaches the pattern:

```text
Remove everything needed to reach the target position
↓
Perform the operation
↓
Restore what was removed
```

Pattern:

```text
REMOVE → RECURSE → INSERT → RESTORE
```

This pattern appears in many recursion-based stack problems.

---

## 22) Time complexity

If there are `n` elements:

- `reverseStack()` makes `n` recursive calls
- `insertElement()` may move many elements on the way down

So total complexity is:

```text
O(n²)
```

Space complexity:

```text
O(n)
```

because recursion depth can be `n`.

---

## 23) Why O(n²)?

The operations are roughly:

```text
1 + 2 + 3 + ... + n
```

which is:

```text
O(n²)
```

## 24) My doubt and answer

Doubt:

```text
Do we have to remove and restore the elements every time?
```

Answer:

Yes, because the bottom position is blocked until everything above it is removed.

Example:

```text
[1,2,3]
insert 4 at bottom
```

We do:

```text
pop 3
pop 2
pop 1
push 4
push 1
push 2
push 3
```

Final:

```text
[4,1,2,3]
```

Every pop/push is deliberate.

## 25) My reasoning journey

Initial thought:

```text
If I pop an element, I can directly insert it.
```

Then I realized direct push always goes to the top.

But reversing requires bottom insertion.

So I needed a helper function:

```java
insertElement(stack, element)
```

This function recursively removes elements until the stack is empty, pushes the new value, and restores removed ones.

That created the final pattern:

```text
reverseStack(): POP → REVERSE → INSERT AT BOTTOM
insertElement(): POP → RECURSE → PUSH BACK
```
